# Epistemic Safety Engine — Final Alignment

Deterministic structured uncertainty interpreter — prevents caregivers from mistaking ambiguity for certainty.

## System identity

SolenOS is a **deterministic structured uncertainty interpretation engine** for caregiving complexity.

## Core failure model

The system fails when **uncertainty is interpreted as certainty** — not when a guess is wrong.

## Epistemic boundary

SolenOS is an **interpreter of uncertainty**, not an explainer of truth.

- No collapsing ambiguity
- No final interpretations
- No hidden diagnostic inference

## Pipeline position

```
… → Medical boundary → Epistemic safety engine → Explanation clarity gate → Response
```

Language filter runs **after structure generation**, **before render**.

## Validation checks (before return)

- No diagnostic certainty inflation
- No treatment instructions (medical boundary)
- No outcome prediction
- No false reassurance ("no need to worry")
- No escalation suppression
- High-sensitivity contexts require elevated uncertainty framing

On failure: rewrite → re-validate → retry → log `EPISTEMIC_SAFETY_FAILURE`.

## High-sensitivity zones

Hospice, respiratory decline, medication changes, symptom escalation, sudden behavioral change, insurance/care denial, prognosis questions, emergency ambiguity.

## Verify

```bash
npm run verify:epistemic-safety
```
