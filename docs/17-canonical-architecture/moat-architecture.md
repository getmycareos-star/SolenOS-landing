# Moat Architecture

**Doc status:** Canonical architecture  
**Module markers:** [module-status.md](./module-status.md) — Family Intelligence + Case Memory = **INTERNAL · IN-MEMORY**; Path A moat = ACS + CRS + SRE + Decision Memory

Five proprietary assets (strategic facade `src/lib/family-intelligence`):

1. **Family Memory** — relationships + observation/memory patterns (**Case Memory** / PRP is the product spine for durable care-recipient facts → intervention compression)  
2. **Care Graph** — ownership / dependence / support  
3. **Decision History** — WHY continuity  
4. **Delegation Network** — who absorbs load over time  
5. **Crisis Prediction** — foresight signals with explanation  

Plus User Trust + Confidence Engine as product rule companions.

**Case vs Situation:** Case = long-lived care recipient product (ADR-012); Situation = runtime STATE root (ADR-001) attached to Case.

Compounding value requires **durable persistence** — currently largely IN-MEMORY with noop Postgres adapters.
